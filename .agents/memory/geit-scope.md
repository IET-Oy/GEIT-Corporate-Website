Use the official logo alone in the header, without an additional company-name text block beside it.

**Why:** The user explicitly removed the duplicated text because the uploaded logo already contains the company name.

**How to apply:** Keep meaningful logo alternative text and a homepage link; do not restore the earlier prompt's adjacent identity text.

Keep all seven desktop navigation links on one horizontal row at the same visual level, in this order: Home, About, Services, Industries & Solutions, Digital Energy Solutions, Insights, Contact.

**Why:** The user explicitly replaced the earlier two-row laptop layout with this requirement.

**How to apply:** Adjust spacing and sizing for desktop widths rather than moving some links into a secondary row. Retain the mobile menu for smaller screens.

Do not add a database, authentication, paid services, or an enquiry-delivery service without approval. The consultation form must not imply that information is sent or stored while disconnected.

**Why:** The user explicitly deferred the database and requested honest validation-only behaviour.

**How to apply:** Preserve the disconnected form until an approved delivery mechanism is requested.
