Use the official logo alone in the header, without an additional company-name text block beside it.

**Why:** The user explicitly removed the duplicated text because the uploaded logo already contains the company name.

**How to apply:** Keep meaningful logo alternative text and a homepage link; do not restore the earlier prompt's adjacent identity text.

Keep all seven desktop navigation links on one horizontal row at the same visual level, in this order: Home, About, Services, Industries & Solutions, Digital Energy Solutions, Insights, Contact.

**Why:** The user explicitly replaced the earlier two-row laptop layout with this requirement.

**How to apply:** Adjust spacing and sizing for desktop widths rather than moving some links into a secondary row. Retain the mobile menu for smaller screens.

The user approved the full phased Energy Intelligence SaaS extension, including authentication, persistent tenant data and private storage. This supersedes the earlier corporate-only prohibition on adding authentication or a database. Preserve the existing corporate site and existing data.

**Why:** The user chose “Begin the full SaaS build in phases” after being offered navigation-only versus the full platform described in the attached master brief.

**How to apply:** Follow the brief’s phased delivery and use Supabase unless an appropriate production-ready backend already exists. Do not silently migrate the legacy database. Keep the public consultation form honest and disconnected until its intake workflow is explicitly implemented; SaaS approval is not evidence that enquiries are already delivered. No paid provider or automatic publishing is authorized.

Use global energy-and-technology positioning throughout visible homepage content, including the homepage footer. Do not apply this as a site-wide removal of company location facts.

**Why:** The user requested that Home contain no Rwanda or Kigali references and position GEIT for international markets, while explicitly preserving registration details, legal information and contact addresses on other pages.

**How to apply:** Keep homepage copy naturally global-facing across all four languages. Scope shared-footer positioning to Home; retain approved address and legal information elsewhere.
